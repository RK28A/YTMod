# YTMod

Version personnelle et améliorée de YTLite.

## Fonctions

- Aucune pub (vidéos, Shorts, fil, recherche)
- SponsorBlock intégré, réglable par catégorie
- Téléchargement vidéo (MP4), audio (M4A) et miniature
- Filtres de l'accueil (masquer les Shorts, masquer les sondages)
- Mode OLED, vidage du cache au lancement, mémorisation de la vitesse de lecture
- Réglages sauvegardés dans le trousseau (gardés après réinstallation)
- Mode sans échec après plusieurs crashs au lancement
- Suit les mises à jour de YouTube : classes renommées gérées, options sans effet masquées
- Anglais et français

Les réglages sont dans les réglages de YouTube, section YTLite.

## Créer l'IPA

1. Onglet **Actions** → **Create YTMod app** → **Run workflow**
2. Colle le lien direct d'un IPA YouTube **décrypté**
3. Coche les tweaks optionnels si besoin (YouPiP, YTUHD, Return YouTube Dislikes…)
4. L'IPA arrive dans **Releases** (brouillon)

Le workflow **Create YouTube Plus app** fait la même chose avec le .deb officiel de YouTube Plus (6.0, 5.2.2 ou 5.2b4).
